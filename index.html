01

THE BEGINNING

Every story starts somewhere.

Ours had moments I never thought I would someday have to leave behind.

MEMORY 01

I remember the smiles.

There were moments when everything felt simple.

MEMORY 02

The little things mattered.

The things we never thought would become memories eventually did.

02

THE MIDDLE

Some moments stay with us.

Even when the people in them slowly become distant.

MEMORY 03

I never knew I would miss this.

Sometimes we understand the value of something only after it becomes a memory.

MEMORY 04

There was happiness here.

And I don't want the ending to erase the good parts.

03

SOMEWHERE ALONG THE WAY

We stopped feeling like us.

Maybe there wasn't one exact moment.

Maybe things simply became quieter, slower, and farther away.

MEMORY 05

I will remember the good.

Not because everything was perfect, but because some moments were real.

MEMORY 06

Even when everything fades.

Some memories don't need a future to have mattered.

And then...

there was silence.

So I finally understood.

MEMORY 07

Thank you for the memories.

I will never need to hate the past just because it ended.

THE LAST MEMORY

Some chapters are meant to end.

And maybe this is where ours quietly closes.

04

ONE LAST LETTER

There are things I never got to say.

So this time, I will say them without asking for anything back.

THE LAST LETTER 2026
Dear Jasleen,
Take care of yourself. — Goodbye
05

LETTING GO

I won't ask you to stay.

I won't ask for a reply. I won't ask for an explanation. I won't chase what has already chosen to walk away.

Some things are beautiful precisely because they happened once.

THE LAST WORDS

Thank You.

For every smile.
Every memory.
Every moment that once felt like forever.

Goodbye.

For the last time.

THE END

Some stories end.
The memories remain.
